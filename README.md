# Garage TN — Fiches techniques

Application web d'atelier (iPhone) : scan du NIV, identification du véhicule (base NHTSA), fiches techniques (huile, pneus, pressions, liquides), option Claude.

Installation : ouvrir https://taxietnavette.github.io/garage-tn/ dans Safari → Partager → « Sur l'écran d'accueil ».

Les fiches et la clé API restent sur l'appareil ; rien n'est envoyé dans ce dépôt.
